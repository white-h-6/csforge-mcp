# 安装与连接 CSForge MCP

当用户只提供本仓库地址并要求“帮我安装这个 MCP”时，按本指南完成接入。安装完成的标准是客户端真实注册工具，并成功读取帮助和当前用户身份；安装不包含创建配方、发布、求购或支付。

## 1. 选择接入方式

先确认当前客户端及其 MCP 配置位置，保留已有服务配置。

- **客户端原生支持 Streamable HTTP：直接连接远端服务。** 按下方地址与认证设置接入，业务工具运行在网站服务端。
- **客户端使用 DeepSeek Harness / Cordis 且需要本地工具适配器：** 按 [local-adapter.md](local-adapter.md) 安装 `dsh-csforge-mcp`。该适配器依赖 Windows DPAPI，仅用于对应环境；不要把它作为所有客户端的通用安装步骤。
- 客户端不支持远端 MCP，且没有适用的适配方式时，说明缺少的能力与下一步。不能仅下载仓库就报告“已安装并连接”。客户端只支持 stdio 时，本服务不是可直接填进 command 的本地程序。

## 2. 配置连接与私密认证

| 配置 | 内容 |
|---|---|
| 服务名称 | `csforge` |
| 地址 | `https://csforge.hkui.ccwu.cc/api/agent/mcp` |
| 传输 | Streamable HTTP |
| 认证请求头 | `Authorization: Bearer <个人密钥>` |

其他自建站点使用该站点实际可访问的 `/api/agent/mcp`，不要把正式站点令牌发给其他站点。地址为 localhost / 127.0.0.1 时，只能由同机客户端连接。

用户在 CSForge 网站顶部“Agent 接入”中创建密钥，点击该密钥旁的“复制密钥”，粘贴到客户端的私密认证设置。没有密钥时可以先准备连接配置，再告知用户完成私密授权；不要要求用户把令牌发到公开聊天。已安全配置的有效令牌可继续使用，无需重复生成。

令牌保存在客户端凭据存储或仅当前用户可读、位于仓库之外的私密配置。不要回显令牌、写进 README、项目源码、命令行参数或日志。客户端支持环境变量或密钥引用时使用其真实支持的方式，不要假设通用占位符会自动展开。

下例仅表达配置内容，字段名须依据当前客户端支持的格式调整；不要把占位符当成有效认证：

```json
{
  "mcpServers": {
    "csforge": {
      "type": "streamable-http",
      "url": "https://csforge.hkui.ccwu.cc/api/agent/mcp",
      "headers": { "Authorization": "Bearer <通过私密设置提供>" }
    }
  }
}
```

需要重新加载客户端才能注册工具时，明确提示用户。不要覆盖其他 MCP 服务或更改账号业务权限。

## 3. 验证接入

1. 确认客户端成功初始化 MCP 并获取 `csforge_*` 工具列表。
2. 调用 `csforge_help` 获取当前站点说明，再调用 `csforge_whoami` 读取当前 Steam 账号、EcoSteam 授权和账号状态。
3. 核对实际返回的账号与用户预期；省略 `steamId` 时跟随网页当前选择，也可显式选择同一连接下属于用户的其他账号。
4. 报告安装位置、是否已连通、当前账号及仍缺少的授权。认证失败、客户端未加载、网络失败、平台未连接分别如实说明。仅配置完成、未通过真实调用时，报告“已配置，待验证”。

验证阶段只读，不通过创建草稿、求购、发布或扣款测试连接。

## 4. 操作入口

安装后、执行用户具体任务前读取 [完整操作 Skill](../skills/csforge/SKILL.md) 和 [工具参考](../skills/csforge/references/tools.md)。工具名称、参数与限制优先核对当前 `csforge_help`、工具 schema 和服务端返回；无法读取仓库文档时说明限制，不能假装读过。

这些文档包含选材、磨损、实际成本、批量预览、合炉/打包预上架、发布、二维码和操作确认流程。用户只要求安装时，完成只读接入验证后等待具体指令。创建前补齐任务参数，不替用户决定售价或付款方式。

写操作返回 `approvalRequired=true` / `approvalId` 时，引导用户在网站“Agent 接入”批准，再用原参数和原幂等键重试。超时或断流先查原操作状态，结果不明时不重新创建订单。账号权限、材料锁、审批和业务校验仍由服务端执行。

## 5. 连接慢或失败

先区分 MCP 初始化、普通库存读取和市场分析。市场分析工作量不同，不能与简单库存读取混为一谈。对照相同工具、参数和网络路径测量，再判断客户端、代理或服务端问题。

特定客户端的网络与超时配置见 [客户端配置说明](local-adapter.md)；增加超时只会延长等待，不能解决连接中断。不要为修复只读超时而对写操作启用盲目自动重试。
